						def computeH(im1_pts, im2_pts):
								n = im1_pts.shape[0]
								if n < 4:
										raise ValueError("At least 4 point correspondences are required.")
								
								A = []
								for i in range(n):
										x, y = im1_pts[i, 0], im1_pts[i, 1]
										xp, yp = im2_pts[i, 0], im2_pts[i, 1]
										
										row1 = [-x, -y, -1,  0,  0,  0,  x * xp,  y * xp,  xp]
										row2 = [ 0,  0,  0, -x, -y, -1,  x * yp,  y * yp,  yp]
										
										A.append(row1)
										A.append(row2)
										
								A = np.array(A, dtype=np.float64)
								
								_, _, Vt = np.linalg.svd(A)
								h = Vt[-1, :]
								
								H = h.reshape(3, 3)
								if H[2, 2] != 0:
										H = H / H[2, 2]
										
								return H

						def get_bounding_box(im_shape, H):
								"""
								Predicts the bounding box of the warped image with safety clamps 
								to prevent runaway memory errors.
								"""
								h, w = im_shape[:2]
								corners = np.array([
										[0, 0, 1],
										[w - 1, 0, 1],
										[w - 1, h - 1, 1],
										[0, h - 1, 1]
								]).T  # Shape: (3, 4)
						
								transformed_corners = H @ corners
						
								z_vals = transformed_corners[2, :]
								z_vals[np.abs(z_vals) < 1e-5] = 1e-5
								transformed_corners /= z_vals
								
								x_coords = transformed_corners[0, :]
								y_coords = transformed_corners[1, :]
								
								all_x = np.append(x_coords, [0, w])
								all_y = np.append(y_coords, [0, h])
								
								x_min = max(int(np.floor(all_x.min())), -2 * w)
								x_max = min(int(np.ceil(all_x.max())), 3 * w)
								y_min = max(int(np.floor(all_y.min())), -2 * h)
								y_max = min(int(np.ceil(all_y.max())), 3 * h)
								
								return x_min, x_max, y_min, y_max
						
						
						def warpImageNearestNeighbor(im, H):
								"""
								Warps image im using homography H with Nearest Neighbor interpolation (inverse warping).
								"""
								h, w = im.shape[:2]
								channels = im.shape[2] if len(im.shape) == 3 else 1
								
								x_min, x_max, y_min, y_max = get_bounding_box(im.shape, H)
								out_w = x_max - x_min + 1
								out_h = y_max - y_min + 1
								
								x_indices = np.arange(x_min, x_max + 1)
								y_indices = np.arange(y_min, y_max + 1)
								X_out, Y_out = np.meshgrid(x_indices, y_indices)
								
								num_pixels = out_w * out_h
								ones = np.ones((1, num_pixels))
								coords_out = np.vstack((X_out.flatten(), Y_out.flatten(), ones))
						
								H_inv = np.linalg.inv(H)
								coords_src = H_inv @ coords_out
								coords_src /= coords_src[2, :]  
								
								X_src = coords_src[0, :].reshape((out_h, out_w))
								Y_src = coords_src[1, :].reshape((out_h, out_w))
								
								X_nn = np.round(X_src).astype(np.int64)
								Y_nn = np.round(Y_src).astype(np.int64)
								
								valid_mask = (X_nn >= 0) & (X_nn < w) & (Y_nn >= 0) & (Y_nn < h)
								
								X_nn_clamped = np.clip(X_nn, 0, w - 1)
								Y_nn_clamped = np.clip(Y_nn, 0, h - 1)
								
								if channels > 1:
										im_warped = np.zeros((out_h, out_w, channels), dtype=im.dtype)
										alpha_mask = np.zeros((out_h, out_w), dtype=np.float64)
										for c in range(channels):
												channel_data = im[:, :, c]
												sampled = channel_data[Y_nn_clamped, X_nn_clamped]
												sampled[~valid_mask] = 0
												im_warped[:, :, c] = sampled
								else:
										im_warped = im[Y_nn_clamped, X_nn_clamped]
										im_warped[~valid_mask] = 0
										im_warped = im_warped.reshape((out_h, out_w))
										
								alpha_mask = valid_mask.astype(np.float64)
								
								return im_warped, alpha_mask

I start by importing the images and converting them from the default BGR format to RGB format. After loading the images, I use pixpy to get the coordinates for the source and target images to create the homographies with and manually input them as arrays in my code.

The computeH function then takes the arrays as input and calculates the homography matrix taking the cordinate arrays as the input. The first check the function does is to check for the number of cordinate pairs in the arrays, if there are less than four coordinate pairs in either of the arrays, it gives an error. The function then uses Direct Linear Transformation (DLT) to create matrix A of size 2N X 9. Where each point correspondence contributes to two rows of linear equations representing Ah = 0. Then the function then factorizes the matri using the Singular Value Decomposition (SVD) and identifies the optimal least-squares solution which forms the parameters of the homography matrix. Finally, the function reshapes the vector into a 3 x 3 matrix format and scales it by its bottom-right element such that magnitude of H equals 1, before returning the final homography matrix. The get_bounding_box function then calculates the spatial boundaries of the warped image taking the source image dimensions and homography matrix as input. First, the function projects the four literal corner coordinates of the source image using the homography matrix and normalizes them by their homogeneous scale factor. Next, it combines these transformed coordinates with the original image bounds and computes the minimum and maximum spatial extents using floor and ceil operations. Finally, it applies safety clamps to prevent runaway memory allocation and returns the integer canvas boundaries (x_min, x_max, y_min, y_max) required to properly size the output warping grid. Now that I have homography matrix and the size of the canvas for my final warped image I will create the final warped image by transforming the source image using the homography matrix and mapping it onto the destination image. I use two different methods and compare how each method affects the processing time and the final result of warping. The warpImageNearestNeighbor function performs inverse warping taking the source image and homography matrix as input. First, it determines the output canvas dimensions and generates a grid of destination pixel coordinates, which it maps back to floating-point source coordinates using the inverse homography matrix and homogeneous division. Next, it rounds these source coordinates to the nearest integer pixel index and applies a validity mask to filter out-of-bounds locations. Finally, it samples the color values directly from the single nearest neighbor at the clamped indices across all channels, returning the warped image along with a binary alpha mask. The warpImageBilinear function does the same inverse warping as the warpImageNearestNeighbor function but where it difers is how it samples the color values, insted of rounding to the closest pixel it takes a weighted average of four surrounding pixel neighbors across each color channel leading to a smooth boundary gradient instead of sharp boundaries avoiding jagged edges.
