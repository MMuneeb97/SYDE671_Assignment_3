Section 1: Convolution & Implementation Methods

Let’s begin by first discussing what a convolution is and look at different ways to implement and how each method effects the processing time and results. Convolution is a way to scan every pixel in an image and extract useful information from it or transform its features to make them more meaningful. Convolution uses a kernel or a filter to process pixels in the context of its neighboring pixels.

The most fundamental way to implement a convolution is by using array functions and for loops. This method helps new users to understand how convolution works. Having this understanding is crucial to further perform useful image processing operations using filters and convolution.


                        #part 1.1: Convolution with 4 for loops
                        import numpy as np
                        import matplotlib.pyplot as plt
                        import cv2
                        
                        img = cv2.imread(r"C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment 2\Me.jpeg")
                        img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
                        
                        kernel = np.ones((9, 9), dtype=np.float32) / 81.0

                        def convolve_with_4forloops(img, kernel):
                            kernel_h, kernel_w = kernel.shape
                            img_h, img_w = img.shape
                        
                            pad_h = kernel_h // 2
                            pad_w = kernel_w // 2
                        
                            padded_img = np.pad(img, ((pad_h, pad_h), (pad_w, pad_w)), mode = 'constant', constant_values = 0)
                        
                            flip_kernel = np.flip(np.flip(kernel, axis = 0), axis = 1)
                        
                            output = np.zeros_like(img, dtype=np.float32)
                        
                            for i in range(img_h):
                                for j in range(img_w):
                                    pixel_sum = 0.0
                        
                                    for k in range(kernel_h):
                                        for l in range(kernel_w):
                                            img_val = padded_img[i + k, j + l]
                                            kernel_val = flip_kernel[k, l]
                                            pixel_sum += img_val * kernel_val
                        
                                    output[i, j] = pixel_sum
                                    
                            return output
                        
                        result = convolve_with_4forloops(img, kernel)
                        plt.figure(figsize=(10,5))

                        plt.subplot(1, 2, 1)
                        plt.title('Original Greyscale')
                        plt.imshow(img, cmap = 'gray')
                        plt.axis('off')
                        
                        plt.subplot(1, 2, 2)
                        plt.title('Filtered (Blurred)')
                        plt.imshow(result, cmap='gray')
                        plt.axis('off')
                        
                        plt.show()

After loading in the required libraries, NumPy to use array functions and matplotlib to plot our images we load in the image and convert it from color to grayscale. Once the image is loaded, we define our kernel; a 9x9 matrix of ones. This is a box filter that will reduce the sharpness and make it smooth. Simply put it makes the image blurred. Next we define our convolution function, we start by padding the image all around with zeros to make sure that the edge features don’t get deleted during the convolution operations as the kernel moves across the image. Next, we define our four nested for loops. The outer loops iterate over the image size (height and width) and the inner loops iterate over the kernel size and perform the dot product over a size of the image equal to the kernel size across the entire image. The results of the convolution are stored in an array and returned at the function call. Below are the results of the convolution performed with the above code.

As expected, the processed image has lost its sharpness, especially around the edges and any thin fine features such the rim of the glasses, the letters on the shirt and hair. Overall, the details and features of the original image are still discernable in the processed image. Next, we will slightly optimize the code to use less processing time and process larger images more efficiently. While using four for loops was an effective way to explain the underlying principle it increases the number of calculations and slows down the processing especially when dealing with larger images or more involved filters. The following code uses only two for loops instead of four to achieve the same effect as before. 


                        #part 1.1: Convolution with 2 for loops
                        import numpy as np
                        import matplotlib.pyplot as plt
                        import cv2
                        
                        img = cv2.imread(r"C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment 2\Me.jpeg")
                        img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
                        
                        kernel = np.ones((9, 9), dtype=np.float32) / 81.0
                        
                        def convolve_with_2forloops(img, kernel):
                            kernel_h, kernel_w = kernel.shape
                            img_h, img_w = img.shape
                        
                            pad_h = kernel_h // 2
                            pad_w = kernel_w // 2
                        
                            padded_img = np.pad(img, ((pad_h, pad_h), (pad_w, pad_w)), mode = 'constant', constant_values = 0)
                        
                            flip_kernel = np.flip(np.flip(kernel, axis = 0), axis = 1)
                        
                            output = np.zeros_like(img, dtype=np.float32)
                        
                            for i in range(img_h):
                                for j in range(img_w):
                                    roi = padded_img[i : i + kernel_h, j : j + kernel_w]
                                    output[i, j] = np.sum(roi * flip_kernel)
                                    
                            return output
                        
                        result = convolve_with_2forloops(img, kernel)
                        plt.figure(figsize=(10,5))
                        
                        plt.subplot(1, 2, 1)
                        plt.title('Original Greyscale')
                        plt.imshow(img, cmap = 'gray')
                        plt.axis('off')
                        
                        plt.subplot(1, 2, 2)
                        plt.title('Filtered (Blurred)')
                        plt.imshow(result, cmap='gray')
                        plt.axis('off')
                        
                        plt.show()

This time we used two for loops instead of four. Instead of iterating over the entire image, this time around we pick a region of interest matching the size of our kernel, perform the convolution calculation and then slide our region of interest one column to the right and repeat for the entire image. Below is the result of this code and you can see the results are identical however the processing time is significantly reduced and larger images can be processed more effeciently with this code.

Next, we take things up a notch and streamline the code even further. We will use the built in convolution function from the SciPy python library this time as it is optimized to perform large calculations very efficiently.

Section 2: Edge Detection Using Difference Operators

Now we will look at another useful way to process images and extract useful information. We are going to look at how to detect the edges of an image using the difference operators. Difference operators are uni-directional vectors that are used to extract magnitudes in the y and x directions. The dy operator works by subtracting the pixel above from the pixel below, this highlights the vertical edges as the operator moves across the image rows from top to bottom. The dx operator works in the same way but in the horizontal direction, capturing the magnitudes of the edges across the image from left to right.

The code below uses the built-in convolve function and dx and dy difference operators to capture the edges of an input image. The convolution function takes care of the padding and also makes sure that output image is the same size as the original image.

We will now take a deeper dive into difference operators and see the individual gradients in the x and y directions along with the magnitude. The gradient is calculated by convolving the image with an x and y difference operator respectively and calculating the sum of the square roots of the gradients in dx and dy. The following code is used to calculate the gradients. 


                        #1.2 Finite diference operator
                        import numpy as np
                        import matplotlib.pyplot as plt
                        import cv2
                        from scipy.signal import convolve2d
                        
                        img = cv2.imread(r'C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment 2\hybrid\cameraman.jpeg')
                        img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
                        
                        dx = [[1, 0, -1]]
                        dy = [[1],
                              [0],
                              [-1]
                             ]
                        
                        grad_x = convolve2d(img, dx, mode='same', boundary='fill', fillvalue=0)
                        grad_y = convolve2d(img, dy, mode='same', boundary='fill', fillvalue=0)
                        grad_mag = np.sqrt(grad_x**2 + grad_y**2)
                        
                        plt.figure(figsize = (5, 5))
                        plt.subplot(2, 2, 1)
                        plt.title('Original Greyscale')
                        plt.imshow(img)
                        plt.axis('off')
                        
                        plt.subplot(2, 2, 2)
                        plt.title('Partial derivative dx')
                        plt.imshow(grad_x)
                        plt.axis('off')
                        
                        plt.subplot(2, 2, 3)
                        plt.title('Partial derivative dy')
                        plt.imshow(grad_y)
                        plt.axis('off')
                        
                        plt.subplot(2, 2, 4)
                        plt.title('magnitude of dx and dy')
                        plt.imshow(grad_mag)
                        plt.axis('off')
                        
                        
                        threshold = [20, 30, 40, 50, 60, 70, 80, 90]
                        
                        plt.figure(figsize= (16, 8))
                        for i, j in enumerate (threshold, start=1):
                            binarized_grad_mag = (grad_mag >= j) * 255
                        
                            plt.subplot(2, 4, i)
                            plt.title(f'Threshold: {j}')
                            plt.imshow(binarized_grad_mag)
                            plt.axis('off')
                        
                        plt.show()

The image below shows the breakdown of the original greyscale into partial derivatives dx and dy capturing the vertical facing and horizontal facing edges respectively along with the combined gradient capturing the entire image.

We have first calculated the gradient magnitudes using convolved function as explained in the previous steps Then we reduce the noise in the image by implementing a binarization loop and pre-defining a list of threshold values. The threshold values are intensity cutoffs for the pixels; any pixels that are greater than or equal to the threshold value are converted to a value of 255 and any pixels below the threshold value are turned to 0. This reduces the noise by emphasizing the prominent edge features and turns the background noise features dark. Below is the sweep of the image for different threshold values.

As you can see that with lower threshold values, we get a lot of background noise from grass and other surrounding features but as we increase the threshold, the edges of the cameraman become crisper and more prominent but as we keep increasing the threshold beyond 60, we start to see the cameraman starts to turn darker and blend in with the surrounding. It is an iterative process to find the right threshold that focus on the important features, too low of a threshold and you’re looking for a needle in a haystack and too high of a threshold and you blend in with the surroundings.

Section 3: Image Sharpening and Unmasking Filter

So far, we have discussed convolution and how to use it to smoothen/blur images. Next, we will look at how to unblur these images using the unsharp mask filter. Since the Gaussian filter we have been using so far retains only the low frequencies from the original image, if we subtract the blurred image from the original, we are left with a sharper image with more high frequencies. The code below does exactly this, it takes an input image blurs it and then resharpens it using this technique.


                        #2.1 Image Sharpening
                        import numpy as np
                        import matplotlib.pyplot as plt
                        import cv2
                        from scipy.signal import convolve2d
                        
                        img = cv2.imread(r"C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment 2\hybrid\cameraman.jpeg")
                        img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
                        
                        orig_img = img
                        
                        sigma = 1.0
                        amount = 0.1
                        ksize = 5
                        
                        gaussian_1D = cv2.getGaussianKernel(ksize = ksize, sigma = sigma)
                        G = np.outer(gaussian_1d, gaussian_1d.T)
                        
                        delta = np.zeros((ksize, ksize))
                        delta[ksize // 2, ksize // 2] = 1.0
                        
                        H_usm = (1.0 + amount) * delta - amount * G
                        
                        sharpened = np.zeros_like(img)
                        
                        for i in range(3):
                            sharpened[..., i] = cv2.filter2D(
                                img[..., i].astype(np.float32), -1, H_usm
                            )
                        sharpened = np.clip(sharpened, 0, 255).astype(np.uint8)
                        
                        plt.figure(figsize=(10, 5))
                        plt.subplot(1, 2, 1)
                        plt.title('Original Image')
                        plt.imshow(orig_img)
                        plt.axis('off')
                        
                        plt.subplot(1, 2, 2)
                        plt.title('Sharpened Image')
                        plt.imshow(sharpened)
                        plt.axis('off')
                        
                        plt.show()

we are using the same kernel as before to blur the image we then create a mask using the H_USM formula by assigning a weight to how much of the frequencies to add back to the original image. Then we iterate through the three color channels, R,G,B, and plot the original and sharpened images.

Section 4: Image Blending

In this next section we will discuss more advanced image processing techniques. We will look at how to create optical illusians by combining a pair of images. By combining the low frequencies of one image to high frequencies of another we can create a visual effect that changes the image featres based on your viewing distance from the image. Since viewing from a distance reduces the visibility of sharp, high frequncy features the low frequency image dominate and when viewing the image from close up, you see more detail i.e the high frequency image.

In principal it sounds like a simple concept, simply take two images, blur the first one using a low pass gaussian filter to obtain the low frequencies from it and for second image subtract its smoothed version from the original to obtain its high frequencies, add the two together and done. In practice however, it takes some trial and error to perfectly align and scale the two together. Any misalignment and you won't get the desired effect you're looking for.

The code below is my first attempt at recreating the Derek-Nutmeg hybrid.


                        #2.2 #2.2 Hybrid Images Nutmeg Derek Colored 
                        import numpy as np
                        import matplotlib.pyplot as plt
                        import cv2
                        
                        img1 = cv2.imread(
                            r'C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment'
                            r' 2\hybrid\DerekPicture.jpg'
                        )
                        img2 = cv2.imread(
                            r'C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment'
                            r' 2\hybrid\nutmeg.jpg'
                        )
                        
                        img1 = cv2.cvtColor(img1, cv2.COLOR_BGR2RGB)
                        img2 = cv2.cvtColor(img2, cv2.COLOR_BGR2RGB)
                        
                        sigma_low = 7
                        sigma_high = 5
                        
                        angle_degrees = 35
                        scale_factor = 1.2
                        tx, ty = 70, 0
                        
                        h, w = img1.shape[:2]
                        
                        h_img2, w_img2 = img2.shape[:2]
                        img2_cropped = img2[
                            int(h_img2 * 0.1) : int(h_img2 * 0.7), int(w_img2 * 0.2) : int(w_img2 * 0.8)
                        ]
                        hc, wc = img2_cropped.shape[:2]
                        
                        center = (wc // 2, hc // 2)
                        M = cv2.getRotationMatrix2D(center, angle_degrees, scale_factor)
                        
                        dst_x = (w / 2) + tx
                        dst_y = (h / 2) + ty
                        M[0, 2] = dst_x - (M[0, 0] * center[0] + M[0, 1] * center[1])
                        M[1, 2] = dst_y - (M[1, 0] * center[0] + M[1, 1] * center[1])
                        
                        img2_aligned = cv2.warpAffine(
                            img2_cropped, M, (w, h), borderValue=(255, 255, 255)
                        )
                        
                        low_freq = cv2.GaussianBlur(
                            img1.astype(np.float32), (0, 0), sigmaX=sigma_low, sigmaY=sigma_low
                        )
                        blur_img2 = cv2.GaussianBlur(
                            img2_aligned.astype(np.float32), (0, 0), sigmaX=sigma_high, sigmaY=sigma_high
                        )
                        
                        high_freq = img2_aligned.astype(np.float32) - blur_img2
                        
                        hybrid_img = low_freq + high_freq
                        hybrid_img = np.clip(hybrid_img, 0, 255).astype(np.uint8)
                        
                        plt.figure(figsize=(15, 5))
                        
                        plt.subplot(1, 3, 1)
                        plt.title('Image 1 (Low Pass Source)')
                        plt.imshow(img1)
                        plt.axis('off')
                        
                        plt.subplot(1, 3, 2)
                        plt.title('Image 2 (High Pass Source)')
                        plt.imshow(img2_aligned)
                        plt.axis('off')
                        
                        plt.subplot(1, 3, 3)
                        plt.title('Resulting Hybrid Image')
                        plt.imshow(hybrid_img)
                        plt.axis('off')
                        
                        plt.tight_layout()
                        plt.show()

In this section we look at how to blend two images together without having a seam at he overlapping edge. if you were to take two images cut them in the middle and join left half of one to right half of the other you will get a dark unnatural seam and abrupt transition from one to the next. In order to avoid this we have to understand that imaes are like a lasagne, made up of layers, each layer contaiing different details that when all stacked on top of each other form an image. This is the technique that Burt and Adelson described in their parper. In order to achieve a smooth transition when joiing two images toether we can get a smooth natural transition if we first split the layers of the image, apply a fade to each layer depending on its frequency and then adding the layers back together to form the final image. By multiplying each layer by a different factor based on its frequency creates an even fade that gradually transitions and blurs out the image near the seam.

The code below is used to recreate the Burt Apple image from Computer Vision: Algorithms and Applications, 2nd ed. by Richard Szeliski.


                        # Laplacian Pyramid Blending (Burt & Adelson style) using Gaussian/Laplacian stacks
                        import cv2
                        import matplotlib.pyplot as plt
                        import numpy as np
                        
                        path = r"C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment 2\ass2 part 2 images"
                        img1 = cv2.imread(path + r"\burt_apple.png")
                        img2 = cv2.imread(path + r"\burt_orange.png")
                        
                        img1 = cv2.cvtColor(img1, cv2.COLOR_BGR2RGB).astype(np.float32) / 255.0
                        img2 = cv2.cvtColor(img2, cv2.COLOR_BGR2RGB).astype(np.float32) / 255.0
                        
                        if img1.shape != img2.shape:
                            img2 = cv2.resize(img2, (img1.shape[1], img1.shape[0]))
                        
                        h, w = img1.shape[:2]
                        
                        mask = np.zeros((h, w), dtype=np.float32)
                        mask[:, :w // 2] = 1.0
                        
                        
                        def build_gaussian_stack(image, num_levels=5, base_sigma=2.0):
                            stack = [image.copy()]
                            for i in range(1, num_levels):
                                sigma = base_sigma * (2 ** (i - 1))
                                stack.append(cv2.GaussianBlur(image, (0, 0), sigmaX=sigma, sigmaY=sigma))
                            return stack
                        
                        
                        def build_laplacian_stack(g_stack):
                            stack = [g_stack[i] - g_stack[i + 1] for i in range(len(g_stack) - 1)]
                            stack.append(g_stack[-1])
                            return stack
                        
                        
                        num_levels = 5
                        base_sigma = 2.0
                        
                        g1 = build_gaussian_stack(img1, num_levels, base_sigma)
                        g2 = build_gaussian_stack(img2, num_levels, base_sigma)
                        gm = build_gaussian_stack(mask, num_levels, base_sigma)
                        
                        l1 = build_laplacian_stack(g1)
                        l2 = build_laplacian_stack(g2)
                        
                        apple_contribs, orange_contribs, blended_stack = [], [], []
                        for a, o, m in zip(l1, l2, gm):
                            m3 = np.dstack([m, m, m])
                            ac = m3 * a
                            oc = (1.0 - m3) * o
                            apple_contribs.append(ac)
                            orange_contribs.append(oc)
                            blended_stack.append(ac + oc)
                        
                        assert np.allclose(sum(l1), img1, atol=1e-4)
                        assert np.allclose(sum(l2), img2, atol=1e-4)
                        
                        blend = np.clip(np.sum(blended_stack, axis=0), 0, 1)
                        
                        
                        def to_display(img, gain, is_residual):
                            if is_residual:
                                return np.clip(img, 0, 1)
                            return np.clip(0.5 + gain * img, 0, 1)
                        
                        
                        levels_to_show = [0, 2, 4]
                        row_labels = ["High frequency\n(level 0)", "Medium frequency\n(level 2)", "Low frequency\n(level 4)"]
                        col_labels = ["Apple (weighted)", "Orange (weighted)", "Combined"]
                        
                        fig, axes = plt.subplots(3, 3, figsize=(9, 9))
                        fig.subplots_adjust(left=0.14, right=0.99, top=0.94, bottom=0.01, wspace=0.03, hspace=0.03)
                        
                        for r, lvl in enumerate(levels_to_show):
                            is_res = (lvl == num_levels - 1)
                            peak = max(np.percentile(np.abs(x[lvl]), 99.5)
                                       for x in (apple_contribs, orange_contribs, blended_stack))
                            gain = 0.5 / max(peak, 1e-6)
                        
                            for c, stack in enumerate((apple_contribs, orange_contribs, blended_stack)):
                                ax = axes[r, c]
                                ax.imshow(to_display(stack[lvl], gain, is_res))
                                ax.set_xticks([])
                                ax.set_yticks([])
                                for spine in ax.spines.values():
                                    spine.set_visible(False)
                                if r == 0:
                                    ax.set_title(col_labels[c], fontsize=10)
                                if c == 0:
                                    ax.set_ylabel(row_labels[r], fontsize=10)
                        
                        plt.show()
                        
                        fig2, ax2 = plt.subplots(1, 3, figsize=(10, 4))
                        for ax, im, t in zip(ax2, (img1, img2, blend), ("Apple", "Orange", "Blended")):
                            ax.imshow(im)
                            ax.set_title(t, fontsize=10)
                            ax.axis("off")
                        plt.tight_layout()
                        plt.show()
